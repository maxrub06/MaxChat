# MaxChat

Responsiv chattprototyp med direktmeddelanden, grupper, emoji-reaktioner, filsval och sökning. Gränssnittet är byggt med HTML, JavaScript och Tailwind CSS.

Öppna `index.html` i en webbläsare för att prova appen. Tailwind CSS hämtas från CDN, så internetanslutning behövs. Konversationer sparas lokalt i webbläsarens `localStorage`, så prototypen kräver ingen server.

**Begränsning:** MySQL, användarkonton, synkronisering mellan användare och faktisk filuppladdning är inte anslutna ännu. Filsvalet visar filnamn och storlek i konversationen; det laddar inte upp filinnehållet.
